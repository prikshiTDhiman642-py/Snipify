# 🎧 AuraAudio — Minimalist Freemium MP3 Extractor

A modern, minimalist web application built with a sleek **dark glassmorphic UI** to extract and download high-quality MP3 audio from Instagram Reels and video links.

---

## ✨ Features
- 🎛️ **Audio Bitrate Selector:** Switch between `128 kbps`, `192 kbps`, `256 kbps`, and `320 kbps (Studio Master)`.
- ⚡ **Freemium Quota System:**
  - **Free Tier:** 3 conversions / 24 hrs (`128k` & `192k`).
  - **Pro Tier:** 50 conversions / 24 hrs with HD audio (`256k` & `320k`).
- 🔑 **License Activation:** Built-in modal to unlock Pro features using license key `PRO2026`.
- 🧹 **Automatic Cleanup:** Temporary audio files are purged right after delivery.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
- **Backend:** Python, FastAPI, Uvicorn, Pydantic
- **Audio Extraction Engine:** `yt-dlp` & `FFmpeg`
